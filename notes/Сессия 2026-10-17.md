# Сессия 2026-10-17 — рыцарь The Ashen Vow из Blender в основной ветке Three.js (Claude)

**Зачем:** рыцарь Tripo, починенный в Blender (PR #76, ветка `feat/ashen-blender-rig-repair-20261017`), лежит в конце цепочки Ashen-веток (#76 → #56 → #55 → #52 → …), которая на 281 коммит экспериментов V2/V12 впереди `experiment/threejs-ascii-prototype`. Чтобы рыцарь появился на основном превью Three.js, не затаскивая эти эксперименты, сделана отдельная ветка `feat/three-ashen-blender-knight` от `experiment/threejs-ascii-prototype` только с новым рыцарем.

**Что в ветке:**
- `experiments/three/assets/ashen-vow/ashen_tripo_blender_repaired_v01.glb` (70k, 4,3 МБ) и `_mobile.glb` (30k, 2,1 МБ): 40 суставов Tripo в исходном порядке, Idle 121 / Walk 69 / Run 85 / Jump 73 кадра при 60 fps, отдельный меч на `bone_19`, цвета вершин.
- `gltf-clip-knight.mjs` (проигрывание запечённых клипов), `native-ashen-blender.mjs` (печать глифами игры, тон по распределению уровней исходного рыцаря, адаптивная частота растра, асинхронное чтение с защитой, `?ashenPerf=1`, `?ashenLod=full|mobile`, `?ashenAsync=0`).
- `native.js`: обёртка `drawKnight` для игрока; `?ashenVow=0` — исходный ASCII-рыцарь; ошибка/редактор/до загрузки — тоже исходный. `native.html`: importmap `three/addons/`.
- Скрипты Blender `blender/ashen/` (без листов приёмки — они в PR #76).
- Проверки `tools/check/ashen-blender-glb.cjs` (без исходного GLB сверяет суставы с записанным списком) и `tools/check/ashen-blender-native.cjs`, в CI.
