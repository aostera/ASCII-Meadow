# Для Claude: как вернуться к работе

Связано: [[ASCII Meadow]] · [[Техническая архитектура]] · [[Визуальное направление]]

## Где что лежит
- Репозиторий `aostera/ASCII-Meadow`, ветка `main`. Игра — `index.html` (только точка входа) + `styles/main.css` + `src/` (код по подсистемам, кадры в `src/data/`), заметки — `notes/`. Карта файлов и правила размещения кода — [[Техническая архитектура]].
- Опубликованный артефакт: https://claude.ai/artifact/J3wgnky6xvhkRMzyJTyV14 (обновлять по этому `url`, сначала `read`).
- Артефакт без обёртки `<html>/<head>/<body>`; в репозитории — та же страница, обёрнутая в полный документ.

## Пользователь
- UX/UI, продуктовый и моушн-дизайнер. Пишет по-русски, коротко. Отвечать по-русски.
- Ценит визуальную точность больше технических объяснений. Эталон — видео.
- Перед заменой стиля — спросить или сверить с референсом. «Один в один» значит использовать исходник, а не рисовать заново.

## Правила, которые пользователь повторял
- Помнить про оптимизацию в каждом изменении: считать один раз и кешировать, рисовать только видимое, мерить CPU кадра.
- Движение должно быть реалистичным, без «желе»: всё качается от одного ветра, тяжёлые вещи медленно.
- Анимируя то, что уже переведено в символы, двигать глифы, а не пересчитывать дизеринг: пересчёт даёт рывки и мерцание.
- Существа в мире (коровы и т. п.) — как деревья: тёмная масса, свет только по верхнему краю, ноги в траве. Не светлые спрайты.
- Части тела животных двигать жёстким поворотом вокруг сустава, а не растяжением/синусами — иначе «желе». Смену рисунков — растворять, не прыгать.
- Плащ — отдельный слой со своей физикой; рисовать отдельно от тела.
- Плащ в движении — как в ассетах (кадры атласа символами), не деформировать его кодом: «странная анимация».
- Ветер двигает только плащ (маска `KCLOAK`, обведена по атласу); рыцарь в стойке стоит и чуть дышит. Угадывать плащ по геометрии нельзя — задевает тело. На границе движущегося и неподвижного — плавный переход в несколько символов, иначе виден срез. Смещения соседних строк одной области должны быть почти равны — иначе полосы.
- Ноги при ходьбе не ломать и не перекрещивать: двигать в пределах нарисованной формы. Проверять шаг на чистом фоне (галерея фаз), а не в траве: трава прячет ноги.

## Ввод
- Пользователь на русской раскладке: клавиши только через `e.code`.

## Как работать
1. Перед правкой перечитать [[Визуальное направление]].
2. После правки: синтаксис (`node --check src/**/*.js`), при переносе кода — детерминированная сверка `tools/check/` (до/после попиксельно), скриншоты Playwright (`/opt/pw-browsers/chromium`, для WebGL флаги `--use-angle=swiftshader --enable-unsafe-swiftshader`), проверить: десктоп, iPhone, старт с нулевым размером панели.
3. В программном рендере fps низкий (~5) — это не реальная цифра. Мерить CPU отдельно, отключив `GL.flush`.
4. Если меняются кадры рыцаря: `tools/to_ascii.py` → вставить `KNIGHT_ART` в `src/data/knight-frames.js`, затем `node tools/find_blades.cjs` → вставить `KSW` туда же. Кадры коров — `COW_ART`/`CIX` в `src/data/cow-frames.js` и `src/entities/cow.js`.
5. Опубликовать артефакт (страница + файлы `src/`, `styles/` через `files`, или одним файлом через `tools/bundle.py`), закоммитить, обновить [[Хронология]] и [[Бэклог]].
6. Новый код — никогда не в `index.html`: свой файл в `src/`, `<script>` в правильном месте, вызов из `simulate()`/`render()`.
