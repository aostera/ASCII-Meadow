## Режимы

1. **Оригинальная игра:** `main`, корневой `index.html`, `src/`, `styles/`, `assets/`. Порядок обычных `script` в HTML задаёт общую лексическую область JS; рабочая версия должна продолжать открываться непосредственно из файла. WebGL2 batched glyph renderer в `src/renderer/webgl.js`, Canvas2D fallback в `src/renderer/canvas2d.js`.
2. **Новый игровой движок:** `experiment/threejs-ascii-prototype`, `experiments/three/native.html` + `native.js` и `native-gl.js` / `three-glyphs.js`. Исходный мир, симуляция и карты используются read-only; GPU glyph stream переносится в Three.js/WebGL2 при сохранении оригинальной художественной фактуры. Один WebGL2 context, Canvas2D fallback и обработка context loss.
3. **Инспекторы:** `experiments/three/index.html` / `parity.html` / `ashen-vow.html` — лаборатории/арт-просмотр. `procedural.html` — исторический prototype. Они не заменяют интеграцию в `native.html`.

## Модули стабильной игры

| Каталог | Назначение |
|---|---|
| `src/core/` | состояние, камера, шум, ввод, tick игрового цикла |
| `src/data/map.js` | авторская `MEADOW_MAP`, единственный источник размещения и штриховых слоёв |
| `src/renderer/` | atlas glyphs, batch, WebGL/Canvas2D, освещение, сборка кадра |
| `src/world/` | terrain/camp/castle/ruins, fauna/flora, grass/wind, fog, lights/shadows, map rebuilding |
| `src/entities/` | knight, cow, NPC catalog/atlas, shared actor logic |
| `src/systems/` | physics, animation, collision, interactions |
| `src/editor/` | интерактивные инструменты и NPC gallery |
| `tools/map/` | безопасный read-only анализ / точный импорт авторского файла по команде |
| `tools/check/` | static и browser тесты, deterministic screenshot diff, performance, native Three QA |

Редактор экспортирует `map.js` в authored координатах с RLE слоями, версией и возможной структурой NPC v2. ``null`` в конфигурации может означать generated default, но не разрешает заменять реальную карту. **При переносе Three.js не изменять карту вообще.**

## Модули Three.js runtime

- `native.js` / `native-gl.js`: orchestrator native, single GPU backend, fallback и lifecycle.
- `three-glyphs.js` / `glyph-visibility.mjs`: instanced GPU глифы, source atlas, order, динамическое исключение перекрытых fragment.
- `source-world.mjs`, `source-masonry.mjs`, `native-architecture-depth.mjs`: исходная архитектура и настоящая source-derived геометрия, архитектурный depth prepass.
- `native-stone-depth.mjs`, `native-tree-depth.mjs`, `native-bush-depth.mjs`: Z-порядок отдельных объектов без переноса/перерисовки исходных объектов.
- `native-bushes.js`, `native-npcs.js`: физика растений и размещение силуэтов NPC в мировой GPU-очереди.
- `native-shadow-coverage.js`, `native-shadow-soften.js`, `native-body-shadows.js`: локальные тени/контакт с землёй, при сохранении source directional casts.
- `native-editor-models.mjs`, `native-mobile-lifecycle.mjs`: инспектор редактора, обработка сенсорного ввода и мобильный lifecycle (уточнять завершение по PR).
- `tools/check/three-*`: детерминированный GPU/on-off-on, native-game, shadow, editor, tree/bush/stone, runtime/performance.

Точная доступность модулей зависит от **ветки**: они не обязаны существовать в `main`. Некоторые экспериментальные 3D модели и glTF находятся только в дочерних draft PR, а не в experiment base.

## Протокол разработки/QA

- Делать одну узкую фичу от свежего experiment в отдельной ветке; PR только в experiment.
- Не менять `src/data/map.js`, production code, исходные атласы, global brightness/alpha. При тестировании 1:1 — source sprites, fog/light и символы без смены тональности; для реальной архитектуры — объёмная 3D depth и проходные арки.
- Проверять конкретный `native.html`, desktop и phone Chromium, редактор, GPU glyphs, fallback, context loss, корректное расположение/порядок теней и реальные changed pixels. Зеленый CI не гарантирует аппаратной производительности или художественной точности.
- [Проверки](../tools/check/README.md); [актуальные CI и очередь](https://github.com/aostera/ASCII-Meadow/blob/experiment/threejs-ascii-prototype/experiments/three/STATUS.md); [визуальный арт-язык](Визуальное%20направление.md).
- Сборка production `sh tools/build_site.sh dist` проставляет ревизии ресурсов и проверяется по Cloudflare build/real endpoint. Без прямого разрешения владельца merge из эксперимента в `main` запрещён.
