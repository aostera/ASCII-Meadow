# Кейс: ASCII Meadow

Связано: [[ASCII Meadow]] · [[Визуальное направление]]

> Черновик. Дописать результаты, добавить скриншоты и запись экрана.

## Задача
Собрать живой мир ASCII-MMORPG: мрачная готика, вид сверху, персонаж, который ходит по полю, и замок, к которому можно подойти. Всё из символов, в браузере, 60 fps.

## Роль
Арт-директор и продуктовый дизайнер: референсы, визуальные правила, оценка итераций. Реализация в паре с Claude.

## Процесс
1. **Трава как основа фактуры.** Физика травинок, ветер, свет облаков.
2. **Поиск персонажа.** Спрайты → скелеты → гравюра → рыцарь из концепт-атласа. Вывод: стиль держит нарисованный вручную источник, код только переводит его в символы.
3. **Поиск архитектуры.** Руины → плоский фасад → 3D-модель, прорисованная лучами. Вывод: в виде сверху здание должно быть объёмным и огромным.
4. **Атмосфера.** Палитра сайта без оранжевого, туман, редкий свет.
5. **Производительность.** Переход на WebGL2: десятки тысяч символов за один вызов.

## Решения, которые стоит показать
- Рыцарь стоит **в** траве: строки рисуются сзади вперёд
- Замок: 3D → символы одной сеткой с травой
- Подъём по лестнице и взаимодействие только у ворот
- Туман, который расступается у огня

## 2026-10-12 — NPC rig motion (draft, PR pending)

Проблема: новым NPC нужны отдельные параметры движения без изменения оригинальных кадров рыцаря, коров и карты. Решение: валидируемые `rigMotion` (`idle.breath`, `walk.stride`, `talk.breath`) в каталоге типов и применение только к процедурному `pose(e)`; добавлен не размещённый на карте тип `hermit`. Ограничения: это не поддержка произвольных покадровых атласов и не готовая библиотека ассетов/предпросмотр. Проверяемый результат: параметры ограничены и заморожены; требуется CI, визуальная проверка и тесты. Для кейса: сравнительная галерея поз NPC и схема пути type → profile → pose. Ссылка на PR будет добавлена после его создания.

### 2026-10-12 — ASCII-превью NPC из production rig (PR #19)

В редакторе прежняя схематичная поза заменена глифовым монохромным предпросмотром: `npcRigPreviewImage()` рисует настоящий `drawRig(e, pose(e))` на изолированном offscreen canvas; редактор преобразует изображение в сетку 30×27 ASCII-символов. Выбор `villager`/`hermit`, `idle`/`walk`/`talk` и фазы шага показывает соответствующий вариант без изменения игрового рендера, RNG, NPC или карты. Добавлены browser-ассерты на повторяемость, различие состояний и изоляцию размера рабочего рига в WebGL2/Canvas 2D. **Ограничения:** это предпросмотр процедурных ригов, а не загрузка произвольных спрайт-атласов и не 60-кадровая анимация; весь этап 1б.2 ещё не закрыт. Проверка нового коммита в CI ожидается. Для портфолио: сравнить два архетипа в одинаковых фазах, показать цепочку каталог → поза → изолированный риг → ASCII. PR: https://github.com/aostera/ASCII-Meadow/pull/19
