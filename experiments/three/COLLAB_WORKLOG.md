## Что GPT сделал — записи в хронологическом порядке

### 2026-10-16 — T02: настоящий портал замка

1. Прорезан оригинальный сплошной каменный gatehouse: настоящий глубокий стрельчатый проём перед исходной **закрытой дубовой дверью** (в отличие от чёрной 2D маски); расширен полупролёт 76→100; увеличена высота острия. Созданы шесть крупных массивных каменных элементов наружной стрельчатой арки.
2. Проверен реальный маршрут от дорожки через все **10 лестничных ступеней** к площадке на отметке Y=120 стандартным `move(player)`, без телепортации. Проверка не доказывает прохождение **через** закрытую дверь.
3. Все 7 CI прошли после монументального портала на коде [1e1d0bd1](https://github.com/aostera/ASCII-Meadow/commit/1e1d0bd142a852d4a70adebe1fdadf3b6bcd885b), [full-art run](https://github.com/aostera/ASCII-Meadow/actions/runs/38925752390). PC 112 686, эм. phone 108 975 отличающихся GPU пикселей в честном zoom=1 on/off/on, 0 ошибок восстановления и карта/путь сохранены.
4. **Отклонены** 2 способа прореживания ASCII кладки: первый давал прямоугольные тёмные заплатки, второй не улучшил чтение входа на телефоне. Оба остаются **default OFF**. На этом остановить эксперименты с мелкой кладкой.
5. Реальные PNG подтверждают лучшее чтение центра, но худ. контроль T02 ещё **не завершён**. PR #54 остаётся draft; нельзя подменять арт-приёмку зелёным CI.

Базовая ротация `ruinRotateMesh` применяется к реальным выпуклым полупространствам, не только к картинке.
3. [T03 QA run 38928898895](https://github.com/aostera/ASCII-Meadow/actions/runs/38928898895) **SUCCESS**: в реальной `native.html` PC + Chromium emulated-phone, GL и Canvas2D оригинальных руин, сохранены карта, проходы, совпадение стен/лучей и одиночный Three canvas; оригинальная теневая функция использует `cast` по этим же solid.
4. **Обнаружен новый дефект:** вершины нового аббатства с `rise=h*.69; tip=rise+h*.42` могут выходить за исходную верхнюю границу baked source raster `h*1.08`; поэтому отдельные лучи верхних фрагментов не попадают в glyph сетку. **Исправлять только экспериментальную геометрию**, не переписывать оригинальный `src/world/ruins.js`: apex теперь `rise+h*.36`, отдельная нижняя полка `rise+h*.32..h*.36`.
5. **Текущий пакет в проверке:** новый `tools/check/three-native-t03-geometry.cjs`: raycast через оригинальную арку с обеих сторон и в каменный простенок, пробные повороты каждой руины `0, ±π/5` (с проверкой box/planes), отдельные front/side геометрические отличия новых массивов от исходных, изменение 3D солнечных лучей над землёй для настоящих теней, guard верхнего габарита `≤ 1.08h`, и 18 дополнительных одиночных PNG для native PC/phone на front/side/back.
6. **Что визуально проверено:** предыдущие скриншоты всех трёх объектов, отличающиеся силуэты. **Что НЕ проверено:** реальные iOS Safari/Android, внешнее художественное согласование, финальный FPS, новые multi-angle снимки — до окончания соответствующего CI указывать статус честно.

## Как двум ассистентам работать без конфликтов

- **Перед работой** открыть этот файл, `experiments/three/AUTO_ROADMAP.md`, PR #54 и #58, проверить реальные `head_sha` и `base`. Никаких догадок по старому превью: публичный Cloudflare preview может показывать **base branch**, а не изменения draft feature PR.
- **Владение файлами сейчас:** GPT редактирует `experiments/three/native-gothic-complete.js`, `tools/check/three-native-t03-geometry.cjs`, `tools/check/three-native-art.cjs`, T02/T03 QA/workflows/архитектурные логи; Claude ведёт персонажей/графические ассеты/GLB, motion-спрайты и их отдельные `experiments/three/assets/<actor>/` модули, не изменяя перечисленные архитектурные файлы параллельно. Это не титулы «арт-директор», а разделение областей ответственности.
- **Перед одновременной правкой общего файла** сначала согласовать владельца конкретного файла/ветку через запись в этот журнал или PR comment; реальную синхронизацию Claude/GPT как будто они в одном чате **не предполагать**.
- После **каждого значимого пакета** дописывать: дата/час, автор, ветка/PR, **какие файлы и что изменено**, причина/отклонённые альтернативы, кодовый SHA, реальные CI URL/исход, PNG/видео URL, что не подтверждено, кому следующий шаг. Не заявлять автоматическую работу «в фоне».
- Для просмотра скриншотов пользователем **не вставлять большие изображения внутрь ответа**. Давать отдельные ссылки на **каждый исходный PNG** (для открытия на весь экран), а также один PDF-альбом с страницами на каждый скриншот и ссылку на GitHub Actions artifact. Отчёт PDF/скриншоты — доказательства, не заменяют live игру.
- Не менять `main`, исходную authored карту, palette, персонажей другой стороны. Вся приёмка нового двигателя проводится в feature PR с desktop/phone QA и при возможности на **физических устройствах**.
